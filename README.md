# The Outliers Second Brain

A second brain built from nothing, on your own machine, with nothing to pay for beyond an AI
subscription you already have.

This is the **all-in-one** version: all four parts in one place, installed by one command.

    git clone https://github.com/OUTLIERS-ai/outliers-second-brain
    cd outliers-second-brain
    python install.py

If you would rather take it a part at a time, each part is also its own repo. Same code, same
guides, sent one at a time instead of all at once.

## The four parts

| | Part | The problem it solves |
|---|---|---|
| 1 | **Memory** | You explain your business to an AI, and it forgets all of it. |
| 2 | **Standards** | A folder accepts anything, and a system that contradicts itself keeps answering confidently. |
| 3 | **Capture** | Everything arrives because you typed it, which is admin, which is what kills these systems. |
| 4 | **Operations** | Capable assistants with no order, no gate, and no way to tell working from broken. |

Each solves one problem you already have. Each works on its own, so you can stop after any of
them and still have something better than you had.

## What you get

    parts/01-memory/       the folder, the rulebook, the copies, the pointer
    parts/02-standards/    your rules as data, the check, the repair tool, the tests
    parts/03-capture/      four ways in, /capture, five assistants
    parts/04-operations/   the record, the morning list, the gate, the timetable
    guide/                  the whole thing as one document

## Reading it

`guide/The-Outliers-Second-Brain.pdf` is the series as one continuous document: what to get right
before you start, then the four parts in order. Straight through once so you know what is
coming, then again a part at a time with the installer open beside you.

## A note on this folder

This repo is **assembled** from the four part repos rather than written separately, so the two
cannot drift apart. If something here disagrees with a part repo, the part repo is right.

## After the fourth part

It loops. What the system tells you rewrites the rules from Part 2 and the sources from Part 3.

And you have a foundation solid enough for another system to stand on. The first one worth
standing there is the one that tracks your interactions with other people.
